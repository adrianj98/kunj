// why kunj

Everything a branch needs, one keystroke away

Stop juggling git stash, half-remembered branch names, and copy-pasted PR bodies. kunj remembers context so you don't have to.

🔀

Auto-stash & restore

Switching branches stashes your dirty tree and restores the right stash when you come back. Never lose in-progress work again.

kunj switch
✨

AI commits & PRs

Claude reads your staged diff and history to write conventional commit messages, PR titles, and full descriptions.

kunj commit --auto
🌳

Worktrees, done right

Spin up a git worktree per branch and hop your IDE straight into it — parallel work without the checkout dance.

kunj tree
🚇

Subway-map git graph

A colorful, Unicode commit graph that actually reads like a map — filter by author, date, or branch.

kunj graph --all
🏷️

Branch metadata

Attach descriptions, tags, and notes to any branch. List and filter your work-in-progress at a glance.

kunj list --wip
📓

Work logs & standups

Every commit is logged to a daily markdown journal. Generate an AI standup summary in seconds.

kunj log
👥

Team dashboard

A web dashboard and Slack reports that roll up PRs and activity across your team.

kunj team
🔌

Shell integration

Tab completion, handy aliases, lifecycle hooks, and your current PR# right in your prompt.

kunj completion --install

        // get started
        
Up and running in a minute

        
Node.js ≥ 20, Git, and a terminal. That's it.

      

      

        

          1
          

            
Install globally

            
$ npm install -g kunj

          

        

        

          2
          

            
Run the interactive setup

            
$ kunj setup

          

        

        

          3
          

            
Create your first branch

            
$ kunj create feat/hello-kunj -d 'my first branch'

          

        

      

      
AI features use your standard AWS credential chain to reach Claude on Bedrock. No keys to paste — just aws configure and go.
